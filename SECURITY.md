# Security Policy

## Supported Versions

Only the latest version of this project is supported with security updates.

## Reporting a Vulnerability

Please do not report security issues to the public issue tracker.
If you have found a security vulnerability, report it privately through this repository's Security tab: choose **Report a vulnerability**.
If that button is not there, email the report to [info@libredb.org](mailto:info@libredb.org) instead.
We will do our best to get back to you soon.
